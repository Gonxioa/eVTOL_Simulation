# 位置、速度任务接口的基准控制调参

日期：2026-10-21。版本标记：`pv_baseline_20261021`。

原来的控制增益沿用含加速度前馈的版本。任务口简化为位置和速度后，默认半径 0.3 m、1–7 秒运动的圆轨迹跟踪误差增大。本次保持任务几何、运动时间、六维接口、内部固定航向、物理模型、反馈结构、积分增益和全部限幅，重新匹配各级控制响应。

## 验证范围

- `BASELINE_TUNING_RESULTS.json`：13 个实际 SLX 工况，包括四种正常任务、三维正弦任务、位置阶跃、扰动悬停、较大半径反向圆轨迹、10/30 ms 延迟下的噪声与风、1/6 号电机部分失效，以及积分步长减半对照。
- `BASELINE_COMPONENT_RESULTS.json`：10 项物理及接口检查，包括悬停平衡、旋翼力矩、电机响应、传感器安装、六维任务接口、姿态及角速度反馈、随机输入可复现性。
- `BASELINE_PYTHON_PARITY.json`：四种正常任务与冻结 Git 基线 Python 方程对照；显式使用当前增益并把加速度和偏航角速度前馈置零。最大位置差小于 1e-13 m，验证实现一致性。
- `BASELINE_DELIVERY.json`：原 `hex_evtol.slx` 更新、保存后重新加载、两处控制参数快照一致、直接运行默认场景及圆轨迹、用户模块名称/位置/时钟封装保留的记录。

噪声、风及 30 ms 延迟组合的圆轨迹测试运行 20 秒，位置 RMSE 约 2.06 cm，最大倾角约 10.01°。这对应本次参数与随机种子，不代表任意风强度或任意延迟下的保证。

初态扰动测试采用位置偏差 [0.1, -0.1, 0.05] m 和 5° 滚转，8 秒时残余误差约 1.53 cm；保留首次检查结果，并延长至 12 秒确认收敛至约 5.00 mm。默认任务仍为 8 秒，正常任务的误差上限未放宽。

调参记录位于 `output/baseline_tuning/`。高增益在理想反馈下误差更低，但引入延迟后产生振荡的候选已排除。首次 Fast Restart 检查发现结构体参数不可调，相关输出以 `fast_restart_invalid` 命名，仅作排错记录；正式验收关闭 Fast Restart，并检查任务参考与风开关确实生效。

## 应用与复现

本次已经直接更新原模型。重新打开 `hex_evtol.slx` 或运行 `open_hex_simulink` 后即可使用已保存增益。更新前的原模型完整备份由 `BASELINE_DELIVERY.json` 的 `backup_model` 给出，包含用户关闭 MATLAB 前保存的编辑。

后续修改场景参数：`P=hex_parameters()`，修改任务/故障设置，再执行 `P=hex_prepare_inputs(P)` 和 `configure_hex_simulink(P)`。

需要将这一组已验收增益应用到其他已打开的旧模型副本时，执行 `update_hex_baseline_model`。该函数先保存完整备份，仅同步五组增益的前两个分量，保留任务、故障设置、其他参数、模块名称、布局和封装。

在独立 MATLAB 会话中执行 `validate_hex_baseline` 可重跑当前增益验收；Python 对照为 `python validation/validate_baseline_python.py`。`validate_hex_simulink` 继续使用冻结的迁移期增益检查历史夹具，并明确记录 `frozen_pre_retuning_gains`，不将历史 16 个工况误报为当前增益的验证。

严重及完全旋翼失效超出本次健康基准修正目标，本次没有把它们标为稳定通过。
