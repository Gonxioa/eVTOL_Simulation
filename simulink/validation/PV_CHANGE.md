# 位置与速度任务接口调整

日期：2026-10-20。

本文件记录接口迁移当天尚未调参的历史结果。2026-10-21 已对位置/速度接口重新调参，当前结果、使用范围和原模型同步记录见 `BASELINE_TUNING.md` 及 `BASELINE_*.json`，不要把下表的历史误差作为当前版本结果。

任务模块现在只输出 `[x;y;z;vx;vy;vz]`，共 6 个数。控制器取消轨迹加速度和偏航角速度前馈，继续使用位置、速度、姿态及机体角速度反馈。姿态和角速度内环、积分、滤波、抗饱和、控制分配、动力学、故障注入和传感器方程均保留。

期望偏航角仍在控制器内部作为常量存在，由 `P.control.yaw_hold_rad` 指定，默认 0 rad。位置/速度误差仍会产生控制加速度，再结合重力补偿计算所需推力及期望姿态四元数。

最初验证副本采用用户较新的自动保存版本。原模型最终以用户保存并关闭 MATLAB 前的最新文件就地更新，包含新增 Display 和已修改的任务模块名称；没有调用完整模型重建。140 个带 SID 模块的名称、类型、位置和所检查的显示属性与最终更新前一致。初始备份保留在 `output/pv_migration/before/`，关闭 MATLAB 前的最新备份保留在 `output/pv_updater_fix/before_live/`。

若 MATLAB 已打开旧接口模型，在命令窗口运行 `update_hex_pv_model`，会先保存一份包含当前未保存编辑的完整备份，再同步嵌入代码与信号维数。这样可以保留内存中尚未写入自动保存文件的时钟图标、布局等编辑。`open_hex_simulink` 和运行/配置入口也会检测旧接口并更新。

初次交付时原 `.slx` 被用户 MATLAB 会话锁定。用户关闭 MATLAB 后，已直接更新原模型并完成编译与 0.02 秒仿真检查；重新打开原 `hex_evtol.slx` 即可运行。`PV_DELIVERY.json` 的 `primary_model_updated` 记录最终同步状态。

更新脚本曾按固定的 `Task Reference/Embedded MATLAB` 路径查找模块，与用户修改后的任务模块名称不匹配。现改为通过当前模型内的函数代码识别目标，使用 `MATLABFunctionConfiguration` 修改代码。`PV_UPDATER_FIX.json` 记录模块、函数块及记录器改名、其他加载模型不受影响、时钟封装及 Display 保留等回归检查，以及原模型更新成功的结果。

## 实测影响

相同物理参数、控制增益、初态和默认任务时序下，8 秒正常任务的位置跟踪 RMSE（先计算三维位置误差范数，再对时间求均方根）如下：

| 任务 | 原前馈版本 | 当前 PV 版本 |
|---|---:|---:|
| 悬停 | 约 0 | 约 0 |
| 直线 | 0.87 cm | 4.45 cm |
| 绕圈 | 5.84 cm | 18.27 cm |
| 升降 | 1.14 cm | 3.09 cm |

默认悬停的状态序列与原版本在 `1e-10` 容差内一致。移除前馈后，运动任务的跟踪误差增加；本次没有为改善上述数值而重新调整增益。
