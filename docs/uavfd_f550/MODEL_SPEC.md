# 独立 UAV-FD／F550 模型说明

本实现按用途划分为带物理量的通用底座、实飞支持的组合基线和单独 demo。F550 与推进组合当前仍是平台线索；未知飞机参数保留 null。出处 ID 见 SOURCE_REGISTER.md，机器台账见 parameter_ledger.json。

## 坐标、状态与单位

世界系 NED（北／东／下），机体系 FRD（前／右／下），原点是整机质心。R 将机体向量转到世界。状态 `x=[p_NED(3),v_NED(3),q_wxyz(4),omega_body(3)]`；q 为 Hamilton 四元数，主动机体到世界旋转，`qdot=0.5*q⊗[0,omega_body]`。`Omega_rotor>=0` 是机械旋翼角速度幅值，单位 rad/s；`omega_body` 单位 rad/s。RPM 转换 `Omega=RPM*2*pi/60`；ESC.RPM 已是历史基础固件电极数换算／slew 后转速，不能再除极对数。原始电极数是否对应真实电机仍未独立核实。

`Body` 必须显式提供正质量、正定惯量、位置、旋向、kT、kQ、g 和证据状态。不读取旧 hex_params。真实机型的完整配置尚不可实例化；demo 与组合基线必须在输出中保留各自状态。

## E1–E6：通用机体与观测

E1：`pdot=v`，`vdot=g_world+R*F_body/m`，`g_world=[0,0,g]`。E2：`J*omega_dot=tau_body-omega×(J*omega)`；E3 为上述四元数更新。基础关系可对照 S03、S05 第 2 节，自行统一为整机 COM 和世界速度的写法。

E4：健康共面固定桨 `T_i=kT_i*Omega_i^2`，`Q_i=kQ_i*Omega_i^2`；`F_i=[0,0,-T_i]`，`tau_i=r_i×F_i-[0,0,s_i*Q_i]`。kT 单位 N/(rad/s)^2，kQ 单位 N·m/(rad/s)^2。s=+1 表示从上方观察顺时针，即 FRD +z 旋转；机体反扭矩方向相反。损伤的 kT_scale、kQ_scale 是分别显式给定的非负参数，未建立其与 5／10 标签的映射。

E5：IMU 比力 `f_sensor=R.T*(a_COM-g_world)+omega_dot×r_sensor+omega×(omega×r_sensor)+a_elastic`。该式由测点刚体加速度推导，r_sensor 是 COM 到传感器的 FRD 向量。静止支撑／悬停在水平姿态下输出 -g 沿 z，自由落体为零。陀螺为 `omega_body+local_angular_rate+bias+noise`；噪声由显式局部 RNG 生成，无未知噪声默认值。

E6：RK4 用真实时间与阶段输入积分，步后单位化 q；另用独立 solve_ivp 参考检查有陀螺耦合的步长收敛。旧 ENU／FLU 适配器 `S_world=[[0,1,0],[1,0,0],[0,0,-1]]`、`S_body=diag(1,-1,-1)`；`R_new=S_world*R_old*S_body`。它只完成坐标转换，不证明旧输入代表同一飞机。

当前底座显式省略气动阻力／风、旋翼转动惯量、动态反扭矩与旋翼陀螺效应、非共面推力、机架气动力以及支撑／接触模型。静止支撑解析检查用已知外力，不模拟起落架。外力／力矩允许显式传入，不隐藏随机扰动。物理参数缺失时不会回退到随机信号。

## E7–E9：不平衡、局部弹性与采样

E7 定义旋转质量一阶矩 `mu=m_e*e`，单位 kg·m，正值表示 theta 方向的等效质量过量（质量缺口可通过相位差 pi 或负 mu 表示）。令 `e_r=[cos(theta),sin(theta),0]`，`e_t=[-sin(theta),cos(theta),0]`、`theta_dot=s*Omega`；质量的相对加速度为 `-e*Omega^2*e_r+e*s*Omega_dot*e_t`，其对支撑的反力 `F_imb=mu*(Omega^2*e_r-s*Omega_dot*e_t)`。缓慢变速可省去切向项。这里只含旋转质量反力；有基础机体运动时省略其与旋转小质量之间的科氏耦合，需在适用性变化时扩展。S05 的多刚体推导支持质量不对称产生旋转激励，本式及符号由上述自由体推导，未复制论文八旋翼数值。

theta 使用转速积分；低频 ESC 无法恢复逐周期真实相位。初始相位是未观测量，demo 明确设定为 0；实飞标定只比较谱与能量，不比较相位。

E8：`Ms*qdd+Cs*qd+Ks*q=B*F_imb`。实现为质量归一的独立局部模态，`wn=2*pi*f_n`、`qdd=-wn^2*q-2*zeta*wn*qd+input_gain*force`，`a_elastic=output_shape*qdd`。q 表示相对刚体的局部弹性位移，不是总加速度。相同外力可分别激励刚体与局部模态，观测只叠加后者的相对加速度。基于线性振动关系自行构造；频率／阻尼／增益均待辨识。单点观测中的 mu、模态参与和传感器传递增益不可分别确定。`LocalModes` 用矩阵指数进行精确 ZOH 线性状态更新；旋转输入的 ZOH 近似仍需步长收敛。

E9：内部积分率依据保留频率设定；观测前低通并禁止超 Nyquist 保留频率或时间外推。demo 比较 1000、2000、4000Hz 内部率，再采样至 300Hz。并非“提高导出 CSV 频率”替代动力学。

## E10–E12：实测转速驱动的组合基线

历史基础固件 S04 的 HEXA X 按 Motor1–6 给出角度 `[90,-90,-30,150,30,-150]` 度，旋向 s=`[1,-1,1,-1,-1,1]`。编号绝非圆周排序；源码第三列为测试顺序，不是电机编号。假定实际保持该布局、等半径与相同推进系数，输入 `U=[sum(Omega^2),sum(-sin(phi)*Omega^2),sum(cos(phi)*Omega^2),sum(-s*Omega^2)]`。真实位置相对 COM 和定制混控仍未独立证实，此模型是条件基线。

E10：`-f_z=a_z*U0+b_z`。a_z 在理想假设下对应 kT/m，但拟合 b_z 同时吸收测点、偏置、遗漏项与建模误差；大截距时不能解释为已辨识的物理 kT/m。E11：`omega_dot_j=gamma_j*Uj+b_j`，理想 gamma 分别是 L*kT/Jx、L*kT/Jy、kQ/Jz；省略 J 差引起的机体陀螺耦合、气动阻尼和输入延迟。gamma 只报告有效组合值。

拟合角速度的积分方程 `omega(t+h)-omega(t)=gamma*integral(U,dt)+b*h`，不用原始陀螺差分。每条飞行拥有相同总拟合权重。只 NO_FAULT1–3 用于正常基线；报告每飞行估计、归一化设计秩／奇异值／条件数。数值满秩不意味着质量／惯量／六组推进系数能分别辨识。

E12：1s 短时预测从测得的角速度、估计姿态／XKF1 速度重新初始化，以转速驱动 E10／E11，预测机体角速度、姿态和估计速度；只构造有效归一化响应，无虚设质量／惯量。姿态误差用 `log(R_observed.T*R_predicted)` 的旋转向量，各轴 rad。该基线与 `Body` 的完整物理模型接口不同，不能假称完整物理开环已标定。长期稳定性和闭环均未验证。

## E13：受限振动观测标定

转频 f_rotor=Omega/(2*pi)。按每条飞行的不重叠 2s 窗估计 Welch PSD，对各旋翼转频 ±5Hz 积分得到三轴能量 E。假定窄带内有效传递近似恒定，`E_j≈G_j*Omega^4`，其来源是 E7 的幅值 mu*Omega^2 和正弦方差 A^2/2；G 含正常／损伤不平衡、机架传递和实际日志处理，单位 `(m/s^2)^2/(rad/s)^4`。频带可重叠，因此 E 不能归属于某个单独旋翼。

健康增益先在每条 NO_FAULT1–3 内取中位数再跨飞行取中位数。损伤增量只由 FAULT_M1_5／FAULT_M2_5 的指定转频带差值估计；原始负增量完整保留，非负限制到零仅代表约束边界，并不证明真实 mu=0。开发 FAULT_M3_5 使用两条标定记录的平均非负增量，这是跨位置可迁移的假设，尚无验证通过依据。

观测模型不拟合真实模态、独立 kT(delta)/kQ(delta) 或缺失质量；也不生成假装真实的 PSD／高频时域。全谱、峰值、三轴能量与 x-y 相干性仅作开发诊断，并检查转速／电压支持区间；同速同压仍不保证运动一致。

正常开发报告中的能量比较使用 Motor1 转频中心带；故障开发使用文件标签对应电机的中心带。二者不是六桨总能量或可分离的单桨能量。当前保留上限为 120Hz，开发转频约 66–113Hz，因此二次及以上阶次均超出该保留带，部分也超过原日志局部 Nyquist 频率。本轮未验证这些谐波，更不能据此断言真实谐波不存在；后续需结合原日志采样、未知固件滤波及更高速观测核查。

## E14 与阶段 D

一阶执行器 `tau*Omega_dot+Omega=Omega_steady(PWM,V)` 的阶跃关系有解析实现及检查，但真实 tau、映射与延迟未知。基础固件在 LogStructure／ESC 处理中包含滤波、转速 slew 与电极数转换；定制高频日志修改尚不可恢复。尚未实现声称复现 ArduPilot 的串级控制、输入整形、抗饱和和混控。进入阶段 D 的门槛在 MODEL_STATUS、VALIDATION_REPORT 中说明。

## 观测处理与排除条件

MAT 以嵌入 *_label 解码，先分别审计三 IMU，再取确切时间戳交集按作者 compare3 方法平均。高频输入是日志 IMU，不能当原始硬件采样；GHz／AHz 是内部传感器速率。VIBE 是经过平方和低通等步骤的统计量，不作原始波形。

候选动力运行段沿用作者 mean(PWM)>=1450 的规则，并要求转速正、有效插值支持、ESC 间隔不超过 0.5s、连续 IMU 间隔不超过 0.03s，排除明确 disarm，最初 ARM 未知比例单独记录；它不是经证实的飞行／悬停判定。筛选后段长至少 8s，两端各裁 3s。绝不把跨停飞缺口连起来积分；不把起飞当真实故障发生时刻。

日志抖动先在每段本地中位间隔对应的整数频率插值整规，这是一个明确近似；降采样前低通，再 resample_poly。低频比较统一 2Hz／20Hz；振动以 120Hz 低通、10Hz 高通／300Hz，受 Nyquist 检查。均为离线 acausal 分析滤波，不重施加 INS_ACCEL_FILTER=20Hz，也未宣称恢复定制滤波。ATT 从度转换弧度并解缠。时钟均保留启动后绝对秒；延迟未知不自动寻优。
