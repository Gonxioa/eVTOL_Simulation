# 六旋翼物理特性说明

本说明仅描述飞机本体的质量、惯量、几何、旋翼/电机和气动参数。以下内容明确
不在本文件范围内：仿真频率与时长、轨迹、世界边界、风场、传感器噪声、故障
注入、控制器增益、GAN及分类器设置。

唯一代码来源为项目根目录的 `hex_physical_characteristics.py`；`main.py` 通过
`hex_params.py` 间接使用这组物理参数。

## 刚体与惯量

| 参数 | 数值 | 单位 | 说明 |
|---|---:|---|---|
| 质量 | 3.4 | kg | F550级六旋翼假设 |
| Ixx | 0.0215 | kg·m² | 工程估计 |
| Iyy | 0.0215 | kg·m² | 工程估计 |
| Izz | 0.0406 | kg·m² | 工程估计 |
| Ixy、Iyz、Ixz | 0 | kg·m² | 假设主惯性轴与机体系重合 |

## 几何构型

- 六旋翼、标准平面Hex-X布局；
- 质心至各旋翼轴距离：0.275 m；
- 旋翼半径：0.127 m；
- 六个旋翼按60°间隔布置；
- 转向符号依次为 `+、-、+、-、+、-`；
- IMU/参考点暂假设位于质心，即 `rI=[0,0,0]`。

## 旋翼、电机与气动参数

| 参数 | 数值 | 说明 |
|---|---:|---|
| k_eta | 5.57×10⁻⁶ | RotorPy约定下的推力系数 |
| k_m | 2.20×10⁻⁷ | 反扭矩系数 |
| k_d | 1.19×10⁻⁴ | 旋翼气动参数 |
| k_z | 2.32×10⁻⁴ | 旋翼气动参数 |
| k_h | 3.39×10⁻³ | 旋翼气动参数 |
| k_flap | 0 | 当前忽略挥舞项 |
| 电机时间常数 | 0.02 s | 一阶电机响应假设 |
| 最小转速 | 0 rad/s | 电机下限 |
| 最大转速 | 1500 rad/s | 电机上限 |
| c_Dx、c_Dy | 0.005 | 机体水平阻力系数 |
| c_Dz | 0.010 | 机体垂向阻力系数 |

在标准重力9.81 m/s²下，由当前质量和推力系数可得到以下一致性检查：

- 悬停单电机转速约999 rad/s；
- 最大单旋翼推力约12.53 N；
- 最大总推力约75.20 N；
- 最大总推力/重量约2.25。

## 可信度边界

当前参数描述的是DJI F550、DJI 2212/920KV级别平台，而不是经过实机完整辨识的
数字孪生。质量、几何尺度和电机等级具有明确参考背景；惯量、若干气动参数与
电机动态参数包含工程估计。若要证明仿真数据具有高物理可信度，应进一步提供：

1. 实机称重与质心测量；
2. 摆振法或CAD得到的惯量矩阵；
3. 电机-电调-螺旋桨推力台标定；
4. 电机阶跃响应得到的时间常数；
5. 飞行日志对姿态、角速度、电机转速和IMU响应的对比验证。
