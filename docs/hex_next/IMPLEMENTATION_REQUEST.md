# 六旋翼故障诊断：当前工作步骤清单

日期：2026-10-09。适用环境：现有 Windows / Python 项目。当前核对基线：`Gonxioa/eVTOL_Simulation` 的提交 `63b9d7ee0dc47e11b5c1aee67e320458f36ed709`。

本清单是下一轮实施要求，尚未执行其中的代码修改。原 A—J 审计与飞控重构已经完成，不按未完成任务重复实施。如果本地已有更新，先核对差异，再把本清单适配到实际代码。

## 研究目标与本轮范围

在一架参数明确、物理假设公开的研究用六旋翼上，建立不向诊断器提供飞行参考的故障识别流程。在相同原始小样本预算、相同分类器和相同测试记录下，比较无扩增、普通重复采样和神经网络扩增的效果。

“未知轨迹”指诊断器不读取参考轨迹、当前目标或未来指令。飞控仍接收当下飞行指令。试验程序可以保存指令用于复现和控制验证，但这些字段不进入诊断特征。

本轮采用现有 Python 仿真与自有串级控制。PX4、Linux / WSL、ROS 2、Gazebo、硬件购买和实飞接入后移。本轮也不把电机效能故障解释为已还原的桨叶缺损机理。

修订说明（2026-10-09）：每一次试验都应有明确任务。当前以“预设任务模板 + 明确参数 + 自动批量生成”为主；诊断器不读取任务信息。在线随机指令只是后续扩展，不是本轮开始仿真的前提，也不要求试验程序对自己的任务未知。

可借鉴 RflyMAD 的实验组织方式：它预先编写包含飞行与故障信息的控制序列，仿真覆盖悬停、航点、速度控制、绕圈、加速和减速，实飞未包含减速类。这里借鉴的是有计划、多工况、可复现的数据采集方式，不表示直接复刻其四旋翼、PX4 或全部实验参数。

研究结果允许出现扩增无改善或负改善；完成标准是比较有效、可复现，不能以必须提高准确率作为筛选数据和修改试验的依据。

## 已完成基础与已知限制

已提交的代码包含独立六旋翼动力学、自有位置—速度—姿态—角速度串级控制、有界六电机分配器、执行器动态、含噪及延迟观测、参数和公式台账、版本与哈希检查。当前核心报告为 27 项测试通过，正常跟踪位置 RMSE 约 0.0316 m，含噪观测反馈约 0.0364 m。这些是原研究工况的结果，新工况要单独验证。

需要解决的事项：

- 正式生成入口主要使用悬停；平滑跟踪验证通过不等于分类器已经跨飞行工况验证。
- 当前学习接口取故障后 3.05—3.65 s 的指定区间，依赖已知故障时刻。
- 当前仅 2 个配对独立 run 组、38 条类记录；两折一轮训练只检查接口。
- `max/median` 补齐策略在类别均衡时可能增加零个样本。
- 欧拉姿态接近奇异区，默认角速度与陀螺三列重复；纯 WGAN 生成的旋转列未满足正交要求。
- Full / Severe 在当前控制配置下越界早停；需要研究故障后的可诊断时段，不能要求所有记录完成同样时长。
- 质量分布、惯量与推进参数仍具有研究设计或候选身份，未与一架真实飞机完成匹配。直接含噪姿态观测也不是完整 EKF。

## 步骤 7：建立无扩增基线，再修复扩增与生成有效性

- [ ] 使用固定原始小样本训练同一个 LSTM，先报告故障检出、位置与严重度分类情况及 19 类混淆；不能因为 19 类难以区分而用类别相关任务或噪声制造差异。
- [ ] 若某些类不可分，检查可观测信号、编号、特征和当前物理模型的限制。分层诊断可作为补充分析，不能悄悄替换原 19 类问题后称为同一结论。
- [ ] 保留四条可比较路径：无扩增、类别加权、普通重复采样、条件 WGAN 扩增。明确主比较和补充比较。
- [ ] 修改生成数量策略：除了补齐不均衡类别，支持每类明确追加数量或比例。例：追加量 `q_c = ceil(r * n_c)`，`r > 0`。报告实际生成、接受与用于训练的数量。
- [ ] 普通重复采样与 WGAN 使用相同额外训练样本数；控制分类器最大更新次数、初始化、早停规则和调参预算，另报告 GAN 的额外训练成本。
- [ ] 扩增比例可以先在训练/验证阶段比较 1× / 2× / 4× 追加量，选择后冻结；不通过最终测试挑比例。
- [ ] 基础方案先使用纯 WGAN，现有物理正则保持关闭。它基于特定稳态命令语义，不适用于所有机动、动态失效或新的特征版本，尤其不能对 Full 失稳窗口统一要求总推力等于 mg。
- [ ] 检查生成信号的单位、有限值、指令边界、分布、频谱及与原始窗口的距离，记录记忆和近重复现象。检查只使用训练/验证数据，不窥视最终测试。
- [ ] 若生成姿态，选择明确的有效旋转输出方案，例如将生成的 6D 表示经声明的解码映射成旋转。零向量/共线等退化输入要处理；同时报告解码前后的分布变化、旋转连续性及与角速度的关系。
- [ ] 数值上的旋转正交不能单独证明动力学有效。检查姿态、陀螺、比力和指令之间的联合关系，容差参考原始模拟观测，考虑观测噪声，不能要求含噪观测逐点精确满足真值方程。
- [ ] 如生成有效性仍未成立，先在 `imu_only` 做纯数据扩增比较，姿态联合生成作为单独待验证项；不得静默修复后将所有生成样本称为物理有效。
- [ ] 增加验证：类别均衡时扩增数量确实大于零；生成样本仅由本折训练数据训练的 GAN 产生；生成后测试数据和标签完全不变。

验收：无扩增基线可以复现；WGAN 分支确实增加训练样本；生成样本的用途和物理证据边界有报告。GAN 成功收敛不是扩增改善已被证明。

- [ ] 冻结各方法超参数、阈值规则、原始训练预算、数据版本和测试 group。对所有方法使用完全相同的未扩增测试记录。
- [ ] 在多个预先选定的原始样本抽取与训练种子下成对比较。建议先从 5 次成对重复起步，再据不确定性决定是否增加；重复种子不增加独立飞行测试量。
- [ ] 主指标报告 Macro-F1；同时报告准确率、各类召回率和混淆矩阵。严重故障漏检不能被 Normal 或其他易分类类别的成绩覆盖。
- [ ] 连续诊断报告健康时间、误报次数/单位健康时间、漏检事件、报警延迟、故障定位/严重度识别及不可评估比例。短健康时长下不只给一个看似精确的误报率。
- [ ] 若报告 ECE / Brier / NLL，固定计算与校准协议；校准参数只在验证集确定，不用测试结果校准模型。
- [ ] 对 Full / Severe，保存从注入到仿真早停的时间，并报告早停前是否报警；早停包络不等于真实碰地或真实危险时刻。未报警记录与不可评估记录均保留。
- [ ] 计算同一测试来源上 WGAN 相对无扩增的指标差值与不确定性；以独立 group 为统计重采样单位，同组跨方法成对、同组不同故障记录共同重采样。不要把高度重叠的窗口当作独立样本构造置信区间。
- [ ] 对未见任务家族、不同噪声/延迟/风及少量物理参数失配分别报告结果。物理失配试验固定控制器名义参数，只改变 plant；质量分布变化时按该分布重算真实 J，不能继续把控制器随 plant 同步改变的设计变体称为失配鲁棒性。
- [ ] 生成样本有效性或原始仿真验证失败时，先解决对应问题再作正式性能主张。效果无改善则完整交付该结果与不确定性，不反复解锁测试集调整到提高为止。

验收：能回答“在什么原始样本预算、飞行条件和故障类别下，扩增是否改善，改善多少，误报/漏检和校准是否同时变化”，并明确不能推广到哪些条件。

## 给本地 Codex 的建议执行顺序

不要把九个阶段混成一次大改。依次交付下列可检查结果；若前项失败，先修复或明确研究边界，再继续依赖它的工作。

| 批次 | 范围 | 交付与验收 |
|---|---|---|
| 第 1 批 | 步骤 1—3 | 旧基线复现；输入数据包与白名单；参数化任务模板与明确试验配置；控制与导出引用一致 |
| 第 2 批 | 步骤 4—5 | 新正常机动验证；19 类故障时段审查；完整时序数据；因果滑窗和回放一致性 |
| 第 3 批 | 步骤 6 | 小规模试跑；独立 group 和任务家族划分；固定小样本预算；冻结正式协议 |
| 第 4 批 | 步骤 7 | 同一分类器的无扩增基线；普通重复与实际非零 WGAN 扩增；生成质量报告 |
| 第 5 批 | 步骤 8—9 | 成对正式比较；逐类与连续诊断指标；未见工况结果；不确定性和完整交接 |

当前优先完成第 1、2 批。正式扩大数据和长时间 GAN 训练在小规模试跑与协议检查之后开展。
