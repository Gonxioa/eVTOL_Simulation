# 本轮新增方程、假设与验收依据

1. 平滑任务进度：`u=(t-start)/(end-start)`，`h=10u³-15u⁴+6u⁵`。
   首尾h的一、二阶导数为0；区间外保持端点。来源是本轮公开的解析构造，非厂家或实飞参数。
2. 直线/升降：`x=x0+d*h`，`v=d*h_dot`，`a=d*h_ddot`。
3. 绕圈：`theta=theta0+turn*h`；`v=radius*theta_dot*tangent`；
   `a=radius*(theta_ddot*tangent-theta_dot²*radial)`。首尾速度和加速度连续。
4. 观测安装转换：传感器坐标比力和陀螺通过已有安装旋转变换到FLU机体系。
   比力依然含重力补偿对应的传感器语义，不能称为惯性系线加速度。
5. 因果滑窗：每50点历史、10点步进；首窗口结束于0.49s。任一窗口只使用其结束时刻及之前的采样。
   无效数据/超出容差的采样间隔清空缓冲；需要重新积累50个连续有效采样。不填补缺失或早停尾部。
6. 离线阶段标签：全窗在注入前为Normal、全窗在注入定义的故障区间为该故障类、跨边界为transition(-1)。
   标签描述注入日程，不证明电机动态已达到稳态。日程不传给诊断器。
7. 报警：故障概率`1-P(Normal)>=0.8`连续3窗后报警；持续高概率锁存，只在解除后允许新事件，冷却1s。
   阈值、窗口、步进均为起步设计；未完成验证集选择或概率校准，不作最优性声明。

验证：`tests/test_continuous_tasks.py`检验解析导数、控制/导出共用参考、未来独立、丢样处理、报警持续规则和故障前配对前缀。
