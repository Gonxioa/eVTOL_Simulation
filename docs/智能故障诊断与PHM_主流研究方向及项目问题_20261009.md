# 智能故障诊断与预测性健康管理：主流研究方向及本项目问题

整理日期：2026年10月9日。

本报告按研究问题和方法归纳，适用于轴承、齿轮、电机、发动机、推进器及其他工业设备。六旋翼仅作为本项目应用对象。分类依据是之前整理的文献及本次核实的一手论文/综述，不作严格的文献计量排名；各方向可以交叉组合。

## 1. 领域范围与任务区分

广义领域是智能故障诊断与预测性健康管理（PHM）。设备对象决定故障机理、可测信号和验证条件，但研究方向应围绕共同问题组织：样本与标签不足、工况变化、机理不完整、观测噪声、多传感器耦合以及部署约束。

- **故障检测**：现在是否异常、何时出现异常。
- **故障诊断**：什么部件/类型出现故障，位置及严重程度如何。
- **故障预测/寿命评估**：健康状态未来如何变化、何时达到失效阈值、剩余寿命（RUL）多少。
- **健康管理**：根据以上结果安排维护、风险处置或运行策略。

诊断分类准确率不能代替RUL预测证据；单一瞬时故障仿真也不能自然变成退化寿命数据。领域任务与常见网络方法可参考[Qiu等，2023工业诊断与预测综述](https://doi.org/10.3390/s23031305)。

## 2. 八条常见研究主线

### 2.1 故障特征学习与多源信息融合

问题：如何从噪声、非平稳信号和多个通道中提取有诊断意义的信息。

方法包括频谱/包络/阶次分析、小波和时频表示，以及CNN、循环网络、Transformer、图网络和注意力融合。振动、电流、温度、压力、转速等可提供互补信息；融合时还需要处理不同采样率、缺失通道和传感器可靠性。

CNN、LSTM、Transformer是技术工具。更有研究意义的问题是：哪些输入有信息、能否区分工况变化与故障、融合是否在独立测试中提供额外收益。[工业诊断与预测综述](https://doi.org/10.3390/s23031305)。

### 2.2 少样本、弱标签与不平衡学习

问题：健康数据多、故障数据少，或者标签昂贵/不完整时如何学习。

常见方法包括类别加权/重采样、少样本度量学习、元学习，以及自监督预训练、半监督学习和健康数据上的异常检测。元学习关注从已有任务中学习快速适应能力；自监督则先使用无标签数据学习表征。

少样本（总信息少）、不平衡（类别比例偏）、弱标签（标注不足或不准）是不同困难，不宜用同一个“扩增样本数量”方案概括。之前的MFEML轴承论文研究跨工况与试验台的少样本适应，是这一方向的例子。[Li等，2025](https://doi.org/10.1016/j.ymssp.2025.112370)、[自监督有限标签诊断研究](https://www.sciencedirect.com/science/article/pii/S0925231225007982)。

### 2.3 生成式数据增强

问题：怎样构造有用的稀缺故障样本，或补足训练分布中的某些区域。

方法包括信号变换、机理合成、VAE、GAN/WGAN和条件扩散等。研究重点不仅是能否生成波形，还包括类别语义、统计与频域特征、样本多样性，以及对独立真实数据的训练收益。

之前的条件DDPM轴承论文使用不同不平衡比例、分类器和增强方法进行比较，并采用GAN-train/GAN-test式评价。它可以借鉴为增强实验设计，不能据此宣称扩散在所有设备上都优于GAN。[Zhao等，2025](https://ieeexplore.ieee.org/abstract/document/10902598)。

### 2.4 跨工况、跨设备与跨域泛化

问题：在一种转速、载荷、设备或实验台上训练，换环境后是否仍有效。

常见方法包括迁移学习、域自适应、域泛化、特征分布对齐、跨域少样本学习及仿真到真实迁移。域自适应可能使用目标域无标签数据；若完全不能见目标域，需要采用相应域泛化协议，不能混用评价条件。

之前的BLDC电机SAON论文使用阶次信息与子域对齐处理转速和工况差异，说明信号机理处理与迁移方法可以结合。[Luo等，2024作者机构记录](https://re.public.polimi.it/handle/11311/1278019)。

### 2.5 物理机理与数据模型融合

问题：数据有限时如何利用已知规律，并抑制物理上不合理的输出。

方法包括模型预测—残差诊断、物理模型加学习补偿、PINN/物理引导网络、参数反演，以及生成模型中的物理损失。物理知识可进入输入、结构、目标函数或输出校验，形式不限于“加一个残差项”。

之前的航空发动机传感器PGNN–CNN研究结合物理性能模型、预测残差与分类；物理引导水下推进器GAN则属于健康数据上的无监督检测。这些方法的任务不同，不能把它们都描述为条件故障样本扩增。[发动机动态传感器诊断研究](https://doi.org/10.3390/aerospace10070644)、[推进器物理引导GAN](https://doi.org/10.1016/j.oceaneng.2023.115585)。

关键问题是物理方程、参数、适用工况和容差是否有依据，以及物理项是否提供额外收益。物理约束也可能带有模型偏差，需要单独评估。

### 2.6 早期异常检测、退化建模与剩余寿命预测

问题：能否在明显失效前发现弱变化，并预测退化趋势。

早期检测常用变化检测、健康基线、重构/预测残差等；RUL研究使用退化模型、状态空间方法和深度时序模型等。发动机Dual Informer与数据增强论文研究的是性能退化预测，与单次故障分类的目标不同。[Zhang等，2023](https://ieeexplore.ieee.org/document/10108951/)。

这类研究需要有退化过程、观测起点、失效阈值和足够长期的记录。评价除了预测误差，还需考虑提前/滞后预测的后果及预测区间。

### 2.7 不确定性、可解释性与可信验证

问题：诊断/预测结果有多可靠，哪些输入支持了结论，何时应拒绝给出确定答案。

方法包括不确定性量化、概率校准、置信/预测区间、共形预测、未知类别识别、OOD检测，以及SHAP等解释方法与机理一致性检查。对概率或区间的保证必须说明假设及分布变化条件。

之前整理的Zio相关RUL文献专门研究不确定性分析和校准，说明这一问题并不限于航空安全。它也影响工业维护决策。[Lin、Yan、Zio，2026综述](https://www.sciencedirect.com/science/article/pii/S0951832025013092)。

复合故障与未知故障识别也是重要问题：多个故障同时存在时，单故障特征可能相互干扰，需要多标签、组合识别或机理分析；测试出现训练未包含的故障时，又涉及开放集/未知类别检测。这些问题横跨表征、少样本、迁移和可信验证，不能默认单故障高准确率意味着能够识别复合故障。[工业诊断与预测综述](https://doi.org/10.3390/s23031305)。

评价协议是所有方向共同的基础：按独立设备/实验/运行划分，避免重叠窗口泄漏；分开训练、调参和最终测试；报告多次重复、误报漏检、最差工况和简单基线。解释热图或高准确率都只构成部分证据。

### 2.8 在线应用、轻量化与分布式维护

问题：如何在边缘设备或多工厂/多设备环境中持续使用模型。

研究包括轻量网络、剪枝/量化、模型蒸馏、流式处理、漂移检测、增量学习和联邦学习。除了识别能力，还需考察计算、通信、存储、维护和更新代价。联邦学习解决数据共享限制，但仍需处理设备之间的分布差异。[工业诊断综述](https://doi.org/10.3390/s23031305)、[联邦迁移故障诊断综述，2025](https://www.sciencedirect.com/science/article/pii/S0888327024007350)。

## 4. 我们项目在这个广义框架中的位置

目前主线可以定位为：**小样本条件下，物理模型与生成增强能否提高故障诊断的真实域泛化能力，并给出可靠验证。**

对应重点是生成增强、物理融合、跨域泛化与可信评价。多源特征学习为其提供输入和识别模型。六旋翼是检验这一方法组合的对象，而不是对文献范围的限制。

目前项目主要研究故障检测/诊断，还没有建立连续退化和寿命预测任务；无需为了覆盖PHM全部方向立即增加RUL网络或联邦学习。

## 6. 汇报时可采用的概括

智能故障诊断与PHM的研究覆盖发动机、轴承、电机和多种工业装备。相关主线包括故障表征与多源融合、少样本与弱标签学习、生成增强、跨工况迁移、物理机理融合、早期检测与寿命预测，以及不确定性和在线应用。我们的项目选择小样本故障诊断作为任务，重点研究物理模型和生成数据能否帮助跨域识别。当前困难在于机理模型和真实观测的一致性、合成样本的故障信息保真度，以及有限独立数据下泛化结论的可信性。
