# 实时故障诊断：训练前计划

基线 362646775e38183381867ba37aa07f729e4195b5，独立分支 codex/realtime-fault-diagnosis-20261123。原项目未提交的 CNN/LSTM 文件复制到独立工作区再修改；原目录不写入。

## 当前实现差异

本地 CNN 已具有四层因果膨胀卷积和缓存（核5，膨胀1/2/4/8，感受野61点），LSTM 为两层64单元。二者都有当前状态头和历史前缀头。旧训练一次读取整条记录，记录/前缀/当前状态损失权重1/0.25/0.25，按验证记录宏F1选择；旧报警以当前头检出、前缀头定位。旧回放需要完整文件，无独立可持续调用的公开对象。旧检出覆盖率可把24秒结束前任意检出视为成功。本轮保留这些语义作明确的旧目标对照，不静默修改旧checkpoint的解释。

## 数据与输入

现有新版原生数据已经采齐：12配对组228条，训练114、验证57、测试57。控制器为 control_recovery_v4_20261122，全部绕圈、24秒、风噪开启、30ms观测延迟。每条2401行，输入加速度计3、陀螺仪3、feedback_state_14..19测量转速6。沿用因果时间对齐：IMU只延迟一次，转速已延迟不再施加。真值和元数据仅进入审计、标签、损失权重及离线评分。标准化逐个训练采样点拟合一次。故障解除才恢复健康标签，飞行恢复稳定不改变故障标签。

## 训练及少量验证候选

先做真实训练来源的小规模训练和因果回放检查。开发阶段仅种子42，比较连续计算段100/300点与故障后前3秒权重1/3的四种组合，CNN/LSTM各训练8次完整来源遍历。按两个网络验证排名的平均名次选共同段长/权重；精确同分先较小权重再较长计算段。

正式CNN/LSTM各做42/43/44三个训练种子，同时在相同新版来源训练旧记录目标对照，共12个正式训练。隐藏维度64、dropout0.3、Adam0.001、batch4、梯度裁剪5、40次完整来源遍历，不按测试结果加预算。每4次遍历验证一次。每个batch先顺序处理整条记录的连续段、累积梯度，最后统一更新一次，因此两种目标的来源遍历数、有效点数及实际优化更新数相同（114条每轮29次更新，40轮1160次）。当前目标每个有效点参与一次加权交叉熵；padding不计入。跨段传递数值状态但分离计算图，历史可影响输出，梯度只能追溯当前计算段。旧目标保留完整反传，区别及计算时间如实报告。

## 验证选型及报警工作点

全部模型共同评价完整24秒验证来源，使用当前状态头的逐时刻宏F1以及在线事件指标。每个检查点比较配置中预先列出的8个工作点，包含原始0.8/0.6阈值、0.3秒检出/定位、0.5秒解除；阈值和确认时长联合比较，保存全部候选，原始工作点单列。

优先要求唯一健康来源和故障前阶段各自每分钟误报不超过1。满足条件后依次比较：1秒内正确电机及程度定位率、3秒内正确定位率、1秒内检出率、逐时刻19类宏F1、首次定位错误比例、误报率及条件定位延迟95分位数。不满足条件时先最小化误报超额，再比较覆盖率。同分优先较早工作点及较早训练检查点。该统计门槛只用于开发选择，0.5/1/3秒只作性能观察点，不是经过闭环验证的安全时限。

旧目标对照同时报告原前缀定位和统一当前头定位，避免把报警逻辑差异全部归因于训练目标。新目标关闭旧记录头训练，其正式整条记录结果采用最后一次在线确认的事件类别；有报警未定位为-1，无报警为健康，不能采用未经训练的旧输出头。

## 事件、曝光及冻结

同一故障事件只匹配故障发生后新发出的正式报警，故障前已激活报警不能回填为成功检出。新报警中的第一次类别确认衡量首次错误；允许后续纠正，但另报首次错误。持续故障中重复新报警及错误解除均计数。检出和正确联合定位的延迟只统计实际发出时刻；条件分位数同时列出未检出及从未正确定位数量。

健康误报以每组唯一健康来源的有效判断区间为曝光，不叠加故障记录重复健康前缀。故障前误报另报其观测秒数及每分钟率，明确配对重复相关性。按电机、故障程度、条件组和训练种子输出。
