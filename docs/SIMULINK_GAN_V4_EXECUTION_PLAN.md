# 六旋翼故障识别与GAN增广：从已有仿真数据开始的完整执行方案

日期：2026年11月5日  
性质：待执行研究协议，可交给本地Codex实施；本文件不表示以下实验已经运行。  
已有证据基线：Gonxioa/eVTOL_Simulation，提交2e033334637be102e9a28c7ce0955d1f7d1f189f。  
目标：每个重要选择都有任务依据、机理依据、文献依据或受控验证结果；如证据不足，明确保留不确定性，不为取得较高分数改变评价口径。

完整顺序：旧结果冻结 → 任务与评价规则登记 → 数据审计 → 真实信号辨识分析 → 窗口长度实验 → 分类器学习能力验证 → 训练时间覆盖实验 → 原始数据基线冻结 → GAN训练与约束对照 → 生成质量验证 → 同量增广比较 → 连续因果回放 → 全方案冻结 → 新独立测试 → 证据汇总。

**执行前必须理解的三个边界。** “训练完成”不等于“充分收敛”，条件标签不等于生成样本的物理真值，验证集上的候选最优不等于全局最优。最终结果可以是GAN没有稳定收益；不能把证明GAN优越作为预设结论。

**已有的12秒依据。** 在V3的12维输入、100点窗口、现有两层LSTM、1000次更新和三个训练种子条件下，前6／12／24秒训练的共同完整24秒验证宏F1均值分别为35.63%、45.83%、41.63%。因此前12秒是该候选集和该配置下的原始分类器选择。它不是已验证的GAN最佳训练时长；V3没有训练前12秒GAN。如果新一轮窗口、模型、预算改变，应重新核对该选择。可以将选中的真实训练池同时提供给分类器、ROS和GAN，以控制相同信息预算。

| 需要区分的量 | 当前含义 |
|---|---|
| 原始记录时长 | 24秒，不因训练选段而缩短或删除 |
| 训练数据覆盖 | 前6、12或24秒范围内符合规则的窗口 |
| 单个窗口长度 | V3为100点，约1秒；新一轮需要验证 |
| GAN输出长度 | 与最终选定的窗口长度一致，不默认生成24秒全过程 |
| 主模型输入 | 加速度计3＋陀螺仪3＋带噪延迟转速反馈6，共12维 |
| 输出类别 | 正常＋6电机×3种剩余效能，共19类 |
| 时间阶段 | 辅助分析元数据，不是分类器输入，也不是新增故障类别 |

**第1步：先登记任务、指标和选择规则。** 在看到新候选成绩前写清怎样作决定。

操作：
- 主任务保持19类窗口识别；同时报告正常识别、故障检测、电机定位和程度判断。
- 主输入固定12维。18维命令＋传感器方案只作辅助信息对照，不能混入12维主结论。
- 标签中的0%、20%、80%均表示剩余推力效能，不是损失比例，也不是转速比例。
- 窗口主指标为19类argmax宏F1；另报准确率、19类逐类召回、正常召回、三个故障程度组内的“电机＋程度联合正确率”。
- 分开计算只要求程度正确的指标，避免用它代替电机定位。
- 连续诊断另报误报事件／健康观测时间、漏检、检出延迟、首次正确定位覆盖和最终正确定位覆盖。
- 暂时没有系统级绝对要求时，不编造99%准确率、某固定漏检率或检出秒数为“适航合格线”。研究指标与未来系统要求分列。

研究选择规则：
- 候选首先必须满足数据和因果性要求。
- 使用共同验证集宏F1作预定主要排序依据，同时列正常与各程度组召回、最差条件组、计算成本及输出类别集中现象。
- 有明显关键类别失效的方案只能作为研究对照，不能因宏F1最高就称为可靠诊断器。
- 未规定不同错误代价时，同时保留Pareto候选及其代价，不事后创造权重使某方案获胜。
- 需要一个暂定研究参考时，按预定主指标排序；同分优先较短窗口、较少更新或较低复杂度。它不等同于部署验收。
- 所有候选、随机种子、选择规则及变更理由写入协议；新增探索与原确认实验分开标记。

产物：研究配置、指标定义、决策记录模板、有限实验预算。

**第2步：审计原始记录、标签和数据划分。** 这里查正确性，不评判模型优劣。

操作：
- 核对每条记录的CSV、MAT、元数据和哈希；检查24秒、100Hz、2401行、连续时间戳、有限值。
- 核对六台电机编号、实际故障注入的剩余效能和原始标签一致。
- 特征来自实际测量链：加速度计3、陀螺仪3、feedback_state_14至19。
- 对齐沿用V3：IMU只补一次相应延迟，已延迟转速不重复延迟。核对实际参数，不仅依据默认配置文件。
- 分类器排除真实效能、估计效能、真实状态、控制分配残差、绝对故障时刻、来源编号和随机种子等字段。
- 每窗保存来源、条件组、起止时刻、物理故障状态、是否跨故障时刻、故障后样本占比。阶段元数据只用于分层分析。
- 原始标签按物理故障状态解释；测量延迟使故障证据较晚到达，应记录这种区别，不能要求传感器在不可观测的瞬间准确报警。
- 按完整配对条件组先划分，再切窗；同一原始记录及其重叠窗口不可跨训练／验证／测试。
- 所有scaler只在实际被选中的真实训练窗口拟合，再用于ROS、GAN和验证／测试。
- 保留完整有限但恢复验收未通过的记录，单独标记；只对真正损坏、标签错误、缺失的数据进行修复或隔离，并记录原因。

现有来源口径：V3正式使用6训练组114条、3验证组57条、3新测试组57条。旧V2测试另行归档。新研究先使用已有训练和验证组开发；已经公开分析的测试记录可作历史错误诊断，不再充当新方法未见的确认测试。

产物：来源清单、标签映射、特征审计、分组检查、scaler拟合来源。

失败处理：先修数据链或隔离损坏记录；不通过降低物理故障强度、删除难类、替换测试种子来“修复识别率”。

**第3步：在真实数据上定位可辨识信息。** 先判断低分主要表现在哪里，再决定是否需要生成数据。

操作：
- 在相同条件组中配对比较：健康与剩余80%；剩余20%的1／4、2／5、3／6号电机；同一故障的初期与后期。
- 时间分层至少包括故障前、混合过渡窗、故障初期、后续时段。用相对故障时刻定义，后段时间标签不等于已经物理恢复稳定。
- 输出代表波形及全部来源统计。代表图按预定来源排序选择，不能只挑最好看的案例。
- 计算每通道均值、标准差、极值、变化率、去均值频谱、自相关、跨通道关系，以及同类跨条件与异类配对距离。
- 距离要参照真实数据本身的噪声和类内变化；t-SNE/PCA只能作辅助图。
- 核对原始数据分类器、ROS的逐类混淆；不能只报三个程度组平均。
- 解释当前两个重点现象：对侧电机定位混淆、轻度故障／正常状态输出集中。机制解释标明为假设或证据一致性，不直接写成严格不可辨识定理。

分支：
- 有明显差异但分类器没利用：优先检查特征表示、优化和模型能力。
- 训练能分、验证不能分：优先检查泛化与来源覆盖。
- 两者都差且原始信号差异很弱：先研究更多历史或更合适的允许观测。单纯扩大GAN不能恢复输入中缺失的信息。
- 不以“低分”单独证明无信息，也不以高维可视化单独证明有信息。

产物：真实信号辨识分析报告、配对图、距离表、原始／ROS错误结构表、待验证假设清单。

**第4步：做受控窗口长度实验。** 先验证一秒是否合适，不直接继承为最优。

初始候选：0.5、1、2、3秒，对应50、100、200、300点。候选是围绕现有一秒方案的有限敏感性设计，不是物理常数。

操作：
- 第一轮固定12维输入、现有LSTM结构和完整24秒训练范围，只改变窗口长度。
- 使用共同窗口结束时刻，使不同长度在相同来源和判断时刻比较；训练步长先固定50点，避免同时改变更新频率。
- 整数索引示例：若最长窗为300点，共同末点可取e=299+50j，且e小于2400；长度W的窗口为[e-W+1,e]。因此不同长度拥有相同来源、标签和结束时刻。
- 健康记录在共同末点取窗；故障记录排除末点早于故障注入的重复健康前缀。跨故障窗按预定末时刻标签处理，但单独报告其故障样本占比与成绩。
- 初始使用训练种子42、43、44，1000次实际更新、批量32；共4长度×3种子=12个LSTM任务。
- 记录完整训练／验证指标、混淆、各阶段成绩、推理耗时和实际计算预算。相同步数不代表相同FLOPs，需报告长度增加的成本。
- 这些共同池计数不同于V3原714／2082／4818，不得直接把差异全部归因模型升级。

选择：保留验证表现与成本有竞争力的最多两个窗口，进入训练预算检查；如没有明显优势，一秒可以保留为低复杂度参考，但不能宣称已证明最优。延长无收益时，不再默认继续延长就能解决信息不足。

产物：窗口长度对照、共同末点清单、窗口选择记录。

**第5步：判断分类器是否真正学好，并确定训练预算。** 把模型能力与观测信息分开检查。

操作：
- 对入选窗口计算完整训练集与验证集的逐类成绩，使用eval模式；不要用某次小批次损失代表全训练集拟合程度。
- 对最多两个入选窗口沿已有优化器检查点续跑到2000、4000次更新，并保存1000／2000／4000结果。不能把“续跑”当作额外独立训练重复。
- 这一组候选用于有限预算敏感性分析；如果4000次时仍持续改善，结论只能限定在当前预算，不能声称充分收敛。
- 用真实窗口统计特征分类器作简单诊断基线；另比较一个预先登记结构的1D-CNN与现有LSTM。简单基线的作用是检查信息和建模假设，不要求所有模型相同参数量，但必须报告参数量、训练成本和搜索预算。
- 不先加入复杂Transformer或把多种模块叠加。
- 分类器从随机初始化开始。选择规则只用验证结果，禁止根据测试结果选择某个训练种子。
- 如换成CNN或改变训练预算，对最有竞争力的两个窗口进行小范围联合复核，不能无限沿用LSTM／1000步下的窗口结论。

判断：训练好、验证差提示泛化；训练和验证都差仍需区分欠拟合、信息重叠与优化不足。不得单凭其中一种现象直接诊断根因。

产物：训练／验证学习曲线、逐类性能、预算敏感性表、模型与最终窗口的联合复核。

---

**第6步：重新确认训练时间覆盖，并做等量对照。** 验证前12秒是否仍是合理选择。

操作：
- 在选定窗口、分类器和训练预算下，仅用真实数据比较前6／12／24秒训练。
- 三个方案均在共同完整24秒验证范围上评价，并分开报告早期和后期表现。
- 所有窗口必须完整落在选定前缀范围内，样本数按实际长度和起止索引重新计算。
- 对验证中有竞争力的短前缀，从完整24秒逐来源、逐类别无放回抽取同量窗口进行对照。
- 等量抽样采用预先登记的多个抽样种子，例如731905、731906、731907；这是复现控制与抽样敏感性设计，不增加独立飞行来源。
- scaler仅拟合每个对照真正选中的窗口。
- 若研究显示时段混合而非总数量是主要因素，可预先增加一项按时间阶段分层抽样的真实数据对照；与前缀截取分开命名。
- 不改变名义任务、PID、故障强度或仿真时长来帮助某个时段获胜。

V3一秒窗口的参考计数，只有条件相同才可直接复用：

| 训练覆盖 | 每条健康记录 | 每条故障记录 | 六个训练组总窗口 |
|---|---:|---:|---:|
| 前6秒 | 11 | 6 | 714 |
| 前12秒 | 23 | 18 | 2082 |
| 前24秒 | 47 | 42 | 4818 |

选择：若12秒仍有验证优势，就固定该真实训练池；若最优改变，如实更新结论。已有12秒结果是初始证据，不是必须保留的答案。

产物：训练覆盖与等量对照、样本计数、选择记录及适用范围。

**第7步：冻结原始数据基线与共同信息预算。** 在开始GAN大规模实验前固定比较对象。

冻结内容：12维特征定义、窗口长度、训练前缀或抽样策略、数据来源、标签语义、scaler拟合来源、主分类器结构、分类器更新预算、评价范围、选择规则。

操作：
- 原始数据、ROS、GAN获得同一套真实训练窗口。
- 例如选中前12秒，则三者都从该池学习；不能让GAN使用额外24秒信息，而ROS仅使用12秒。
- 可以把12秒作为共同预算选择，不需要声称它是GAN自身的最佳训练时长。
- 若专门研究GAN训练覆盖对比，必须新增成套匹配的真实数据／ROS对照，单独说明信息预算变化。
- 若原始分类器仍有关键类别输出集中，保留它作为研究参考，不把它当成生成标签的真值裁判。

产物：原始数据基线冻结收据、共同训练池哈希、待做增广清单。

**第8步：先训练可复现的条件GAN基线G0。** 不先假定升级网络会更好。

操作：
- 与选定窗口长度一致，生成W点×12通道的候选窗口；类别条件为原19类。
- 主实验不向分类器提供绝对时间、故障时刻、指令或真实效能。离线标签用于监督与评价。
- G0沿用现有条件WGAN-GP的核心结构；新增版本化日志，不改变已冻结V3行为。
- 原生成器起始设置可作为预算参考：学习率1e-4、critic每G步更新5次、梯度惩罚权重10、G最多3000步，保存500／1500／3000检查点。这些是已有实现与文献起点，不是已证明的本项目最优值。
- 使用三个生成器种子，保留优化器、随机流、采样索引、模型权重与实际参数变化证据。
- 每个检查点使用固定随机输入与类别探针，观察同一生成任务随训练变化。
- 分别记录真实与生成平均critic评分、二者差值、梯度惩罚、G／D总损失、梯度范数和非有限值。
- 在同一图上比较G和D时说明记录平均方式；不能把G的单批损失与D的多批均值的平滑程度直接比较。
- 不依据G损失最低、损失为负或曲线变平宣布类别正确或收敛充分。

产物：G0三个种子的实际训练记录、分解损失曲线、固定探针输出、检查点与预算收据。

**第9步：依据错误类型增加约束，并保留消融。** 一次只回答一个改进是否有效。

默认的第一项改进为G1：加入故障类别一致性约束，思想来自ACGAN／GPSC-GAN。明确写成“受文献启发的变体”，除非完整复现，否则不冒称论文原模型。

操作：
- 先在真实训练数据上训练辅助分类器，并在真实验证数据上检查其逐类能力。
- 可采用冻结的真实数据辅助分类器对生成器提供分类损失指导；最终下游分类器仍从头独立训练，不直接复用该辅助分类器权重。
- 对辅助分类器无法辨识的类别，不把其输出当作生成数据真值，也不把低一致率直接等同于生成错误率。
- 类别约束权重的有限候选及来源写入配置，包含0权重的无约束对照；所有选择只使用验证阶段。
- 若发现主要不足是时间相关性，再增加G2：受TimeGAN启发的时序约束变体；与G0／G1做独立消融，不能同时更改长度、数据池、架构和损失后归因单一因素。
- 若真实数据证明需要跨窗历史，则独立建立上下文生成与有状态识别实验；不得把随机片段直接拼成假连续序列。
- 如果加入阶段条件，阶段只供离线生成与分析使用，不能作为在线分类器已知答案。没有阶段条件的生成窗口不得凭空标成某个具体绝对时段。

产物：G0／G1及必要时G2的设计、引用、改动清单和消融结果；失败变体完整保留。

---

**第10步：分层验证生成质量，候选标签不能直接当物理真值。** 质量验证与下游增益分开。

操作：
- 生成质量的主要参考来自所选训练覆盖范围内、类别匹配的真实验证窗口，不能仅把短前缀GAN与完整24秒分布的差异解释为GAN学习失败。
- 另保留共同完整24秒验证，评价下游模型的全时段泛化。
- 窗口内检查波形、变化率、去均值频谱、自相关和跨通道关系；逐类报告，避免平均值掩盖某几类失败。
- 统计分布检查包括归一化Wasserstein、KS等；多样性检查包括精确重复、训练最近邻和类内覆盖，参照真实样本之间的自然变化。
- 真假判别分数、分类一致率、t-SNE、频谱相似都只是证据的一部分，没有任何一个自动证明故障标签正确。
- 参考分类器只在真实训练数据上学习；做生成数据训练、真实验证数据评价的TSTR类实验，检查生成信息能否转移到真实样本。
- 区分类别条件与阶段混合。G0不提供具体阶段条件时，按其可用类别混合分布评价；如需逐阶段可控生成，必须另建阶段条件。
- 物理检查必须能由可得变量闭合计算。缺少命令或完整状态时，不伪造电机／刚体动力学残差作为物理证明。
- 不能把控制命令限幅当作IMU测量上限；带噪转速观测在停转附近可能出现小负值，不能简单按机械真转速非负规则删除。
- 不照搬其他论文SSIM、MMD的数值阈值。阈值参考真实训练／验证差异及预先登记规则确定。
- 若启用筛选，保存尝试生成数、接受数、拒绝数、各类别原因和多样性变化。筛选不是保证全部标签正确。
- 检查全部最终入选窗口的有限性、数量与重复；昂贵质量诊断可采用固定分层抽样，但必须说明覆盖范围。不能以608个探针的检查冒充全部样本穷尽检查。

选择：GAN检查点由验证阶段的质量与预定下游验证规则确定；不看正式测试，不追求最漂亮损失图。关键类别没有可信证据时，不称为高保真故障样本。

产物：分层质量表、真实／生成波形、去均值频谱与关联图、TSTR结果、筛选及标签可信度说明。

---

**第11步：验证GAN增广是否超过同量ROS。** 把数量效应与生成内容的价值分开。

操作：
- 原始、ROS、GAN使用相同真实训练池、主分类器、初始化种子、scaler与分类器更新预算；分类器分别从头训练。
- 比例初始候选为0、0.25、0.5、1.0，逐类新增数为floor(n_c×rho)。
- 若GAN筛选后数量减少，ROS匹配最终实际加入训练的逐类数量；同时报告GAN为凑足这些样本的成本。
- 当前按每类同比例增加的ROS不是专门纠正少数类不平衡；在报告中说明它主要是重复抽样对照。
- 分类器训练本来有放回抽样，ROS在固定更新数下主要改变个体窗口权重及批次路径，不能把改善归因“训练步数变多”。
- 如要解释ROS机制，可增加比例1的均匀复制对照；它与随机有放回复制分开命名。
- 至少保留三个分类器训练种子；生成器种子、分类器种子和ROS抽样种子分别登记，避免把所有波动混成一个来源。
- 分别报告GAN−ROS和GAN−原始数据的逐种子、逐条件组差值。窗口重叠不能作为独立样本量。
- 不仅比较宏F1，也比较正常、每个严重度的联合识别率、最差电机和最差条件组。
- 不增加GAN额外分类器更新而保持ROS不变。需要更大预算时，给所有方法相同的预声明第二预算，并单独报告。

V3原一秒窗口参考，不预先当作V4最优：

| 情况 | 原始 | ROS新增 | GAN新增 | 各自扩充后总数 |
|---|---:|---:|---:|---:|
| 前6秒、比例1 | 714 | 714 | 714 | 1428 |
| 前24秒、比例0.25 | 4818 | 1204 | 1204 | 6022 |

前12秒原2082窗：如果仍为原一秒切窗，比例0.25时逐类新增520窗，总2602窗；比例0.5时新增1041窗，总3123窗；比例1时新增2082窗，总4164窗。以上由健康138窗、每故障类108窗分别向下取整得到，模型或窗口改变后重算。

结论规则：仅当GAN的实际收益在来源与随机性上有足够支持、且未隐藏关键类别恶化，才能按相应范围声称增广有效。GAN没有稳定超过ROS时，如实报告，不挑种子。

产物：同量对照、逐类数量、实际更新收据、配对差值、成本及失败记录。

---

**第12步：进行完整24秒因果连续回放。** 单窗分类与连续诊断是两个评价层次。

操作：
- 推理只使用当前与过去的真实传感器数据；GAN不参与在线窗口生成。
- 标准化器只transform，不在测试记录上重新fit。
- 先沿用0.1秒判断周期作为已有工程参考，另记录计算耗时；它不是已经证明的最优实时周期。
- 窗口长度改变后，首次可判断时刻、判断次数和健康曝光时间都要重算，不能统一套用231次或69秒。
- 当前独立窗口LSTM不传递上一窗口隐藏状态；报警状态机的持续次数不等于LSTM跨窗记忆。若更改为有状态模型，必须单列协议并验证初始化、清除、误报后的行为和状态变化。
- 阈值与持续次数只在完整验证记录上选择。可沿用V3候选阈值0.1至0.9及持续2／3／5作为起始网格，但其依据是有限敏感性设计，不能称为行业合格标准。
- 不在真实故障时刻重置模型，不给模型输入故障发生时刻；故障前已持续激活的报警不能算新检出。
- 健康曝光按每组唯一健康记录计算，不能把18条故障记录的重复健康前缀当成18份独立正常试验。
- 检出率和定位覆盖率的分母包含漏检。条件平均延迟须与漏检率一起报告。
- 输出按电机、剩余效能、来源及时间阶段分层的错误。单窗argmax与阈值报警成绩保持分列。
- 当前研究先是离线因果回放，不把结果写成诊断网络已经接入容错飞控或实机实时通过。

产物：验证工作点、逐记录回放、检出／定位延迟、健康曝光和代表误报／漏检图。

---

**第13步：冻结新研究的全部选择，再建立独立确认。** 既有V3测试不能成为新方法唯一确认依据。

冻结内容：数据与代码身份、输入、窗口、训练范围、模型、训练预算、scaler、GAN变体与检查点、增广比例、筛选规则、报警参数、评价规则和所有候选选择记录。

操作：
- 记录已经曝光过的风噪种子和原始来源；新确认来源不得重复。
- 新测试组数依据开发阶段的组间变化、希望分辨的收益大小／精度及预算，在采集或解锁前确定。
- 如需要样本量规划，可用组级配对差值的波动作近似规划，说明小规模开发数据估计不稳；不把“新加三组”或“跑三个训练种子”自动称为统计充分。
- 预算有限时可以完成较小确认，但应相应限制结论，不持续追加直到出现显著正结果。
- 每个配对条件组为1健康＋18故障；n组对应19n条原始记录。全部仍保留24秒。
- 首轮确认可以保持同一绕圈任务和故障模型，仅改变独立扰动来源。不同任务、不同故障时刻、参数失配属于另外预先规定的泛化层次。
- 数据完整性与来源哈希允许审计；正式测试的特征、预测和指标在冻结前不用于调参。
- 所有冻结方法统一评价新测试，保留每个失败来源。不能根据确认结果再换检查点、比例或工作点。
- 如果新测试导致再次开发改进，另立版本，并需要新的独立确认。

产物：冻结收据、新采集计划、原始记录、一次统一测试结果及来源隔离证据。

**第14步：按问题而非按漂亮图写报告。** 每个结论能回到具体实验和适用条件。

必须交付：
- 数据来源、分组、计数、哈希与标签规则。
- 真实信号可辨识证据及尚未验证的机制解释。
- 窗口、训练预算、分类器、时间覆盖和等量抽样的选择依据。
- 原始基线的训练／验证逐类表现。
- GAN结构、文献来源、分解损失、类别与时间约束消融。
- 生成质量、抽样范围、筛选、重复与多样性。
- 原始／ROS／GAN的逐类同量、同预算对照。
- 完整24秒连续诊断以及全部关键异常。
- 新独立测试、组级不确定性与成本。
- 仿真范围、未验证任务和实机差距；不以代码测试数量代替识别或飞行验收。
- 所有训练任务实际更新数、生成数、检查点、日志；不存在“只写入口未实际训练却报告完成”的情况。

推荐最终结论形式：在明确的输入、窗口、真实数据预算、模型预算和独立条件范围内，哪种方法改善哪些指标，哪些类别仍失效，哪些结果未超过简单基线。

**第15步：给每个重要选择写一条决策记录。** 不是先选答案，再补理由。

| 字段 | 必填内容 |
|---|---|
| decision_id | 可追溯的唯一编号 |
| question | 该实验回答的具体问题 |
| candidates | 预先规定的候选与范围 |
| basis | 任务／物理／文献／工程预算依据 |
| controlled_variables | 保持不变的条件 |
| validation_rule | 在何种验证范围、用何指标选择 |
| evidence | 数据、配置、结果和图的路径及哈希 |
| selected | 选择结果或不作唯一选择 |
| scope | 只适用于什么输入、任务和预算 |
| limitations | 尚不清楚或未通过的部分 |
| status | 待执行／已验证／不支持／需复核 |

示例：前12秒作为共同训练池，可以由原始分类器的验证结果和公平信息预算得到支持；“GAN用12秒最优”需要另一个明确的生成／增广对照，不能用前一句替代。

**建议的最小执行批次。** 先跑便宜、能改变后续决策的实验。

批次A，不训练GAN：
1. 完成步骤0—3的数据审计、错误结构和配对波形。
2. 完成4种窗口×3训练种子的初筛。
3. 对最多两个窗口补训练预算、训练／验证逐类诊断和简单模型对照。
4. 复核前6／12／24秒与必要等量控制，固定共同真实训练池。

批次B，进入增广：
1. 固定原始数据参考，训练G0和一个类别约束变体。
2. 用验证数据检查质量与实际增广收益；仅在有证据时增加时序或上下文变体。
3. 比较比例0／0.25／0.5／1，匹配ROS最终数量，校准连续诊断。
4. 如果GAN不能稳定超过ROS，完整交付负结果，不把模型复杂度当贡献。

批次C，独立确认：
1. 冻结全部选择。
2. 按预先确定的计划采集／解锁新来源。
3. 一次统一评价并报告范围；是否扩大研究由仍未解决的问题决定。

### 1. 来源和边界

基线固定为2e033334637be102e9a28c7ce0955d1f7d1f189f。分支为codex/simulink-gan-v4-evidence，结果目录为output_simulink_gan/v4_evidence_20261105。复用原六个训练组和三个验证组；既有V2/V3测试均归为已经曝光的历史来源。旧记录、权重、scaler及收据只读，身份写入legacy_snapshot.json。

### 2. 两种窗口网格分开命名

第一轮窗口对照固定共同末点e=299+50j，e<2400；每组健康43窗、每条故障42窗、每组799窗，六个训练组4794窗、三个验证组2397窗。50/100/200/300点窗口共用相同末点、来源及标签。

在3.49秒结束的窗口，物理故障样本占比依次为100%、50%、25%、16.67%。另记录transport_eligible_fraction，表示经过已知传输延迟后的时间占比，它不证明证据已可辨识。

最终窗长确定前，最多两个入选窗长在原生网格e=W-1+50j上重新做LSTM/CNN联合复核；原生窗口从0秒开始。第6步的前6/12/24秒覆盖比较全部使用原生网格，并重新拟合各自scaler、训练模型。共同网格与原生网格的缓存和优化器不得静默复用。

### 4. 唯一的主排序口径

每个训练种子先合并三个验证组的共同评价窗口计算固定19类argmax宏F1，再对三个种子等权平均。保留8位小数后同分，依次选择较短窗口、较少更新、较少参数、模型名。关键类别、最差组和成本同时保留；主指标最高只表示研究参考，不是可靠诊断器验收。

训练预算从1000/2000/4000中选择。4000次仍改善时，只能陈述当前预算范围内结果，不能声称已充分收敛。前缀从6/12/24秒中按同一验证规则选择，同分优先较短前缀。阶段指标同时保存实际支持数、固定19类和出现类别宏F1；纯故障18类阶段的固定19类宏F1上限为18/19。

### 5. G1进入条件与有限GAN范围

G0复用原类别条件WGAN-GP核心结构，输出选定长度×12维。G1为ACGAN/GPSC启发的冻结外部教师类别约束变体，不能冒称原论文复现。

G1仅在共同真实基线的三个种子都满足以下最低非塌缩检查时开展探索：19个类别的验证召回均大于0，且健康召回、剩余80%类别的电机＋程度联合正确率均高于1/19。这个门槛只排除明显塌缩教师，不证明标签可信，也不是系统合格线。若未通过，保留失败证据，跳过G1，继续G0/ROS研究。

类别约束权重候选固定0、0.1、1.0；0为G0。首轮G2关闭，生成样本筛选关闭。所有入选合成窗口都检查有限值、实际数量和精确重复；昂贵质量诊断使用每类固定32个探针，明确覆盖范围。质量主要参照所选训练覆盖内的真实验证窗；另做完整24秒下游评价。

生成器种子142/143/144、分类器种子42/43/44、ROS抽样种子242/243/244按序配对，属于三个联合重复，不据此分解生成器与分类器各自的方差。生成器上限3000次G更新，每G步5次critic、梯度惩罚10、学习率各1e-4，保存500/1500/3000。损失分项与固定探针不改变训练随机流。

增广比例0/0.25/0.5/1.0，逐类floor(n×比例)。G0/G1候选与ROS使用同一真实池、scaler和已冻结分类器预算。按三种联合重复的共同完整验证宏F1选择，同分优先较小比例；GAN−同量ROS和GAN−原始结果均保留。质量一致率不由同一教师独自验收。

### 6. 连续报警时钟

原生因果回放使用0.1秒判断周期，每个记录从其首个完整窗口开始；不在3秒重置。50/100/200/300点窗口首次判断依次为0.49/0.99/1.99/2.99秒。3秒窗在注入前只有一次判断，必须报告其预故障曝光局限。正常曝光按唯一健康来源和实际可判断区间计算，不复用V3固定的231次／69秒。

主窗口argmax与概率阈值报警分列。报警阈值0.1～0.9和持续2/3/5仅通过验证选择。任务phase受容错参考调速影响，名义第7秒不保证实际运动结束；phase和恢复状态只用于离线分析。

### 7. 独立确认的预算规则

全部开发完成后，主确认比较固定为所选GAN相对同量ROS。用三个验证条件组上、先跨训练种子平均的配对宏F1差值计算样本标准差s。预算规划取n=clip(ceil((1.96s/0.05)^2),6,12)，即6～12个全新条件组。0.05是本轮预算规划的目标半宽，不是系统误差要求；只有三个开发组的近似正态规划估计不稳，不能承诺达到该精度或统计充分。

在采集前固定n、未用过的连续风噪种子和停止规则；不因测试结果再追加。先完成所有模型、scaler、比例、工作点和来源的冻结，才允许读取新测试特征。确认的独立统计单位是配对条件组，不是重叠窗口，也不是训练种子。
